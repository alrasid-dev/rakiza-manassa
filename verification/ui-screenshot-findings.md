# نتائج المعاينة البصرية

**التاريخ:** 2026-08-20

ظهرت شاشة الأفراد بقوائم أقسام قابلة للفتح والإغلاق، ويظهر عدد الملفات داخل كل قسم مع بحث الاسم والبريد، دون قائمة تجميع واحدة للموظفين. ظهرت صفحة رفع التقرير بعناوين مختصرة وقبول PDF وDOCX وXLSX. ظهرت صفحة المساعد المتخصص لكل قسم مع نطاق الصلاحية والتنبيه بأن الاعتماد النهائي بشري. لم تُنفذ أي عملية تشغيلية من المعاينة؛ التحقق كان بصرياً فقط.

على الجوال بعرض 390×844 ظهرت بطاقة تثبيت التطبيق، وتكيفت صفحة الأفراد وصفحة رفع التقارير وصفحة المساعد دون قص أفقي ظاهر. بقيت القوائم منسدلة والحقول وأزرار الرفع قابلة للاستخدام بصرياً، مع بقاء التحقق الوظيفي الفعلي لتسجيل الدخول والرفع مرتبطاً بجلسة مصادق عليها.
