# نتائج معاينة الجوال

بتاريخ 2026-08-20 تمت معاينة `/people` و`/login` و`/report-upload` بعرض 390 وارتفاع 844. صفحة الأفراد متجاوبة وتعرض نموذج إضافة الملف، قائمة القسم، البحث، والتكليف ضمن بطاقات عمودية مناسبة للمس. صفحة الدخول متجاوبة وتعرض OTP ومفتاح المرور وطلب التسجيل. صفحة رفع التقارير ظهرت في لقطة تحميل هيكلي أثناء انتظار طلب البيانات؛ لا يظهر في السجل فشل HTTP، ويجب انتظار اكتمال الجلب أو اختبارها بعد جلسة مصادق عليها.

## تحقق إضافي

عند فتح `/report-upload` دون جلسة مصادقة، أعادت الصفحة المستخدم إلى بوابة رَكيزة المستقلة مع خيار الدخول وطلب التسجيل. هذا سلوك حماية صحيح، وليس حالة تحميل عالقة؛ اختبار نموذج الرفع نفسه يتطلب تسجيل دخول مصادقاً.
