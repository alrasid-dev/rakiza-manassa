# تحقق بيان PWA المنشور

تم فتح الرابط الخارجي: https://courtplat-3wct5pog.manus.space/manifest.webmanifest

النتيجة المنشورة: JSON صالح يحتوي على `name` و`short_name` بقيمة «رَكيزة»، `lang` العربية، `dir` rtl، `display` standalone، `start_url` و`scope` بقيمة `/`، و`theme_color` أخضر. يتضمن أيقونة 192x192 وأيقونة 512x512 maskable عبر مسارات manus-storage.

الرابط البديل https://courtplat-3wct5pog.manus.space/manifest.json أعاد صفحة 404، وهو متوقع لأن index.html يربط المسار الصحيح `/manifest.webmanifest`.

تم التحقق من البيان المنشور فقط؛ لم يُنفذ ضغط زر إضافة إلى الشاشة الرئيسية على جهاز Android أو iOS فعلي من بيئة الخادم.
