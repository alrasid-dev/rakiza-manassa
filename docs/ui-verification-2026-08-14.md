# نتائج التحقق البصري

تمت معاينة لوحة القيادة، وصفحة إرفاق وتحليل الملفات، وسجل الحركة في جلسة منصة فعلية على سطح المكتب. ظهرت هوية RTL بشكل متسق، مع شريط جانبي منظم وبطاقات واضحة للمتابعة وسجل حركة قابل للتصفية.

كما تمت معاينة لوحة القيادة وصفحة الإرفاق على شاشة جوال بعرض 375 بكسل. تحولت البطاقات إلى عمود واحد، وبقي النص العربي مقروءاً، وظل مربع رفع XLSX وخيار اعتماد الملف كمصدر مرتبط قابلين للوصول دون قص أو تداخل ظاهر.

يتطلب التحقق النهائي بعد النشر اختبار الوصول بصلاحيات المستخدم الإداري والملازم القضائي كلٌّ على حدة، ثم إنشاء وظيفة الجدولة الحية للمصدر المرتبط.

تمت كذلك معاينة صفحة شؤون القضاة؛ ظهرت كوحدة مستقلة في تسلسل الأقسام مع حالة فارغة آمنة عند عدم وجود ملفات قضاة ضمن النطاق المخول. تتطلب بعض لقطات المعاينة إعادة فتح الجلسة بعد إعادة تشغيل الخادم لأن مصادقة المعاينة لا تستقر دائماً في اللقطة الأولى.

عند معاينة صفحتي الدعم التقني ودليل المستخدم في جلسة غير مصادق عليها، ظهر هيكل التحميل فقط؛ وهذا متوقع لأن الصفحتين تستدعيان بيانات الحساب والصلاحية قبل إظهار المحتوى التشغيلي. فحص TypeScript والاختبارات الآلية نجحا بعد إضافة الصفحتين. يلزم التحقق التفاعلي بعد الدخول بحساب منصة معتمد.
