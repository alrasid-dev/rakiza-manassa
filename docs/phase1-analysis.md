# تحليل الإصدار الأول: وحدة شؤون الملازمين

## النطاق المعتمد

يركز الإصدار الأول على وحدة شؤون الملازمين بوصفها نقطة الانطلاق للمنصة الداخلية. ويشمل ذلك ملفات الموظفين الإداريين والملازمين، سجل المهام الدورية، سجل المتعثرات، التقرير اليومي للحضور، الإعلانات، سجل القرار والمساءلة، والتقارير القابلة للتصفية. ستبقى بنية البيانات قابلة لإضافة وحدة شؤون القضاة والأقسام الأخرى دون تغيير جوهري في الصلاحيات الأساسية.

| مجال المصدر | ما تم التعرّف عليه | قرار التحويل داخل المنصة |
|---|---|---|
| سجل المهام | 39 مهمة مرقمة، موزعة بين مهام يومية وأسبوعية وشهرية وربع سنوية، مع مكلفين متعددين وحالات تنفيذ. | قوالب مهام متكررة تُنشئ مهام تشغيلية قابلة للإسناد والاعتماد والتصعيد. |
| سجل المتعثرات | 229 سجلاً مع تصنيف، تاريخ نشوء، إجراء متخذ، جهة متابعة، موظف متابع، وحالة معالجة. | سجل متعثرات دائم، مع خط زمني للتحديثات ومالك متابعة ومسار تصعيد. |
| بيانات الأفراد | ثلاثة موظفين إداريين فعليين و117 صفاً للملازمين في المصدر. | سجل أفراد موحد مع تاريخ المصدر وحالة تحقق قبل التفعيل النهائي. |
| تقرير الحضور اليومي | نموذج يعرض الدائرة، نمط الحضور، وقت الحضور، الحالة، مدة الملازمة والملاحظات. | تقرير حضور يومي قابل للاستيراد والمراجعة وربط الإجازات والملاحظات. |
| ملف المتعثرات الأسبوعي | قالب منظم من تسعة حقول للعنوان والتشكيل والملازم والإجراء والمتابعة والاستحقاق والحالة والأولوية. | قالب استيراد موحد للتحقق المسبق قبل إنشاء أو تحديث سجل المتعثرات. |

## الأدوار ومسار السلطة

يتبع كل إجراء سلسلة إدارية ظاهرة وغير قابلة للتجاوز تقنياً. يملك رئيس المحكمة الرؤية النهائية والاعتماد الأعلى، ويعمل الرئيس المساعد ضمن التفويض الموثق فقط. يدير مدير شؤون الملازمين الإسناد والمتابعة والرفع، بينما ينفذ الموظف الإداري المهام المسندة إليه دون منح نفسه صلاحيات اعتماد. يستطيع الملازم القضائي الاطلاع على ملفه وما يطلب منه وتأكيد الاستلام أو الإدخال ضمن الحدود المصرح بها. وستضاف صلاحية القاضي/القاضي المشرف كدور مستقل عند تثبيت نطاق شؤون القضاة.

| الدور | نطاق العرض | إجراءاته المسموحة | قيوده الجوهرية |
|---|---|---|---|
| رئيس المحكمة | كافة الأقسام والملخصات النهائية | الاعتماد النهائي والاطلاع والتفويض الموثق | لا تتجاوز قراراته سجل التدقيق أو الأرشفة. |
| الرئيس المساعد | حسب التفويض والمستوى الإداري | اعتماد ضمن التفويض، توجيه، متابعة | لا يتجاوز صلاحية الرئيس أو مدة التفويض. |
| مدير شؤون الملازمين | الوحدة التابعة وسجلاتها | الإسناد، المراجعة، الرفع، إدارة المتعثرات | لا ينفذ اعتماداً محجوزاً لمستوى أعلى. |
| موظف إداري | المهام والسجلات المسندة إليه | التنفيذ والتحديث وطلب الاعتماد | لا يعدل السجلات المعتمدة أو نطاق غيره. |
| ملازم قضائي | ملفه وطلباته وتكليفاته | الاطلاع والتأكيد والإدخال المصرح | لا يصل إلى ملفات الآخرين أو التقييمات الإدارية. |

## جودة البيانات واستيرادها

سيوفر الاستيراد معاينة وتحقيقاً قبل الحفظ. يتضمن ذلك كشف الحقول الناقصة، التكرارات، اختلافات صياغة التواريخ الهجرية والميلادية، الصفوف التجريبية أو الشاغرة، والملف ذي التنسيق غير القياسي. لن تُنقل البيانات المرفقة تلقائياً إلى بيئة التشغيل قبل اعتماد مسؤول الجهة لخطة التصنيف والاحتفاظ؛ بل ستُستخدم لصياغة القوالب وقواعد التحقق أولاً.

## تكامل Microsoft 365

سيتم استخدام تسجيل تطبيق خاص بمستأجر الجهة للمصادقة المؤسسية. أما ملف المتعثرات في Teams، فسيقتصر الوصول إلى مورد محدد فقط بعد موافقة المسؤول ومنح صريح للمورد؛ هذا يمنع أن تتحول موافقة التطبيق إلى وصول شامل لمحتوى Teams أو SharePoint.[1] ويحتفظ التطبيق بسجل لكل عملية قراءة أو استيراد أو تعديل مرتبطة بملف المصدر.
