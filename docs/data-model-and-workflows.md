# نموذج البيانات ومسارات العمل

## مبادئ التصميم

يعمل كل إجراء على سجل أصلي، ومسار اعتماد، وسجل تدقيق مستقل. لا تُستبدل السجلات المعتمدة أو المحذوفة بإزالة فعلية؛ بل تحفظ حالتها ومرجعها ووقت الإجراء وصاحبه. وستُخزَّن التواريخ التشغيلية بصيغة UTC، مع عرضها بالتوقيت المحلي للمستخدم.

| المجال | الكيانات الرئيسية | الغرض |
|---|---|---|
| التنظيم والصلاحيات | الأقسام، إسنادات الأدوار، التفويضات | تعريف القسم والمالك والصلاحية ومدة التفويض. |
| الأفراد | ملفات الأشخاص، بيانات الموظف، بيانات الملازم، بيانات القاضي، التشكيلات | فصل بيانات الحساب عن الملف الإداري والوظيفي. |
| المهام | قوالب المهام، المهام الفعلية، الإسنادات، تحديثات الإنجاز | تحويل الملفات الدورية إلى مهام قابلة للتتبع. |
| الاعتماد | طلبات الاعتماد، خطوات الاعتماد، التفويضات | فرض المراجعة بالترتيب وعدم القفز بين المستويات. |
| المتعثرات والمساءلات | سجل المتعثرات، التصعيدات، ملفات المساءلة، التعليقات | حفظ أصل التعثر ومتابعته ونتيجته. |
| التقييم | أحداث النقاط، ملخصات الأداء، مؤشرات التأخر | احتساب قابل للمراجعة دون تعديل يدوي صامت. |
| الإشعارات | قوالب الإشعار، سجلات الإرسال، نتائج القنوات | إرسال متزامن للتطبيق والبريد مع إثبات التسليم أو الفشل. |
| الاستيراد | دفعات الاستيراد، صفوف التحقق، مصدر الملف | معاينة Excel والتحقق قبل إنشاء أو تحديث السجلات. |
| التدقيق | سجل تدقيق غير قابل للحذف من الواجهة | توثيق من فعل ماذا ومتى ومن أي مسار. |

## مسار المهمة اليومية

تنشأ المهمة من قالب معتمد، ثم تُسنَد إلى موظف أو أكثر عند بداية نافذة العمل. يثبت الموظف الاستلام ويحدث التقدم، ويستقبل مدير شؤون الملازمين الحالات المتأخرة. وعند انقضاء الست ساعات دون إكمال أو تبرير معتمد، ينشأ حدث تأخر ويُرفع وفق مصفوفة الاعتماد؛ لا تؤدي القاعدة إلى عقوبة آلية نهائية من دون فرصة تحديث أو مراجعة إدارية.

| المرحلة | المنفذ | النتيجة | الضوابط |
|---|---|---|---|
| إنشاء القالب | مدير شؤون الملازمين | قالب دوري مع مكلفين ووقت استحقاق | لا ينشر القالب إلا بعد اعتماده بحسب السياسة. |
| توليد المهمة | خدمة مجدولة | مهمة فعلية لكل فترة تشغيل | عملية قابلة لإعادة التنفيذ دون إنشاء تكرارات. |
| الاستلام والتنفيذ | الموظف الإداري | تحديث موثق وحالة تقدم | لا يمكن تعديل بيانات الإسناد أو الاعتماد. |
| المراجعة | مدير شؤون الملازمين | قبول، إرجاع، أو تصعيد | يملك المدير صلاحية المراجعة لا تجاوز المستوى الأعلى. |
| الاعتماد النهائي | الرئيس المساعد أو رئيس المحكمة | نتيجة معتمدة عند الحاجة | يعمل الرئيس المساعد ضمن تفويض صالح فقط. |

## مسار القرار والمساءلة

تبدأ القرارات والمساءلات كمسودة أو طلب رفع. تنتقل بعدها عبر مدير الوحدة ثم الرئيس المساعد ثم رئيس المحكمة عندما يتطلب نوع الإجراء ذلك. كل انتقال يسجل الخطوة الحالية وصاحبها والتعليق والوقت، ولا يمكن لمستخدم اعتماد خطوة ليس مخولاً بها. ويسجل الرفض أو الإرجاع كحدث مستقل بدلاً من محو الطلب.

## قواعد النقاط

يستند التقييم إلى أحداث واضحة، مثل إنجاز في الموعد، تأخر مثبت بعد انتهاء مهلة المراجعة، قبول تبرير، أو اعتماد إنجاز استثنائي. تحفظ كل نقطة سببها ومصدرها وسياقها، ويُحظر تعديل الرصيد مباشرة من الواجهة. تتطلب التسويات الإدارية طلباً مستقلاً مع سبب واعتماد وتدقيق.
